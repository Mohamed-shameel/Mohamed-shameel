### 🛒 RationMate — Public Distribution System Inventory

<a href="https://rationmate.onrender.com/">
  <img src="https://img.shields.io/badge/Live%20Demo-RationMate-46E3B7?style=for-the-badge" alt="RationMate live demo" />

<a href="https://github.com/Mohamed-shameel/rationmate">

</div>

A full-stack inventory management platform for ration shops under India's Public Distribution System (PDS). RationMate helps citizens check stock availability before visiting a shop, reducing unnecessary travel and long queues.

**Key features**

- **Shop owners:** Secure password login and an inventory dashboard to add, update and remove stock.
- **Citizens:** Password-free OTP login through SMS and a view of nearby ration shops.
- **Live stock status:** Colour-coded availability indicators — green for available, yellow for low stock and red for out of stock.
- **Role-based access:** Separate authentication flows for shop owners and citizens.

**Tech stack**

`Node.js` · `Express` · `MongoDB Atlas` · `Mongoose` · `JWT` · `Twilio OTP` · `bcrypt` · `Helmet` · `Vanilla HTML/CSS/JavaScript` · `Render`

### ⚡ CIT RISE — Research & Innovation Student Ecosystem

An AI-powered campus innovation ecosystem for **Chennai Institute of Technology**, designed to bring student achievements, career intelligence, opportunities and mentor connections into one platform.

**The problem**

Student innovation data is often scattered across spreadsheets, personal files and separate platforms. This makes it difficult for students to present their work, for mentors to discover talent and for the institution to understand its innovation ecosystem.

**What CIT RISE offers**

| Feature | Implementation |
|---|---|
| AI profile generation from resumes | Google Gemini |
| RISE Innovation Score with explanations | Google Gemini |
| Personalised career roadmap | Google Gemini |
| GitHub repository analysis and skill detection | CareerNav AI + GitHub API |
| LeetCode statistics and DSA study plan | CareerNav AI + LeetCode GraphQL API |
| Admin talent-intelligence dashboard | Google Gemini |
| AI chat assistant (EduBot) | Google Gemini |
| Achievement submission and verification | Admin-managed |
| Mentor and alumni recommendations | Skill-based matching |
| Opportunity broadcasting | Admin-managed |

**CareerNav AI integration — Team Helios**

- **GitHub analysis:** Retrieves public repositories and uses Gemini to classify project domains, skills, skill levels, career readiness and open-source activity.
- **LeetCode analysis:** Retrieves coding-practice statistics and generates a personalised DSA study plan and interview-readiness assessment.
- Detected skills can be added to a student's CIT RISE profile and used during innovation-score recalculation.

**Core modules**

- Innovation Profile System — AI-generated student profiles from resume content.
- RISE Score Engine — AI-generated innovation score with supporting reasoning.
- Career Roadmap — Personalised milestones, skill gaps and career guidance.
- CareerNav Intelligence — GitHub and LeetCode analysis.
- Mentor & Alumni Engagement — Skill-based mentor matching.
- Event & Achievement Tracker — Achievement uploads and admin verification.
- Opportunity Broadcasting — Internships, competitions and research opportunities.
- Admin Dashboard — Institutional analytics and talent insights.

**Architecture**

```text
React Frontend
      |
    REST API
      |
FastAPI Backend
      |
In-memory Store (demo) → Firebase Firestore (production)
      |
Gemini API + GitHub Public API + LeetCode GraphQL API
```

**Tech stack**

`React 18` · `Python` · `FastAPI` · `Google Gemini` · `GitHub Public API` · `LeetCode GraphQL` · `Firebase Firestore` · `Render` · `Vercel`

**Team:** Team CIT RISE — Chennai Institute of Technology  
**CareerNav AI integration:** Team Helios
